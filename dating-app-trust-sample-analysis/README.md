\# dating-app-trust-sample-analysis

This repository contains a sample of analysis code from an independent mixed-methods study examining trust and authenticity cues, and online-to-offline dating behavior.



\## Overview

The purpose of this repository is to demonstrate:

\- Analytical workflow in R

\- Research decision-making

\- Reproducible methods

\- Ethical handling of participant data

This is a curated sample, intended to illustrate approach and thinking rather than provide a full replication package.



\## What's Included

\### Scripts

\- 01\_sample\_data\_prep\_and\_quant.R



Sample data preparation workflow and one representative quantitative output.

\- 02\_sample\_qual\_pipeline.R



Qualitative text analysis pipeline comparing language associated with “fake” versus “trusted” dating profiles (tokenization, sentiment analysis, topic modeling, and synthesis).

\### Outputs

\- Aggregated tables and summaries generated by the scripts (e.g., frequency tables, sentiment summaries, topic top terms).

\- All outputs are privacy-safe and do not contain raw participant text.



\## What's Not Included

\- Raw or cleaned datasets (protected for participant privacy)

\- Raw open-ended responses or verbatim quotes

\- Full analysis outputs



Additional materials (e.g., full datasets, extended analyses, and qualitative excerpts) are available upon request for interview or research review.



\## Ethical Note

This repository intentionally limits shared materials to methods and summaries.

Design decisions reflect standard UX research and academic ethics practices around participant privacy, informed consent, and responsible data sharing.
