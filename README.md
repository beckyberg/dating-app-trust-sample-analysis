# dating-app-trust-sample-analysis
This repository contains a sample of analysis code from an independent mixed-methods study examining trust and authenticity cues, and online-to-offline dating behavior.

## Overview
The purpose of this repository is to demonstrate:
- Analytical workflow in R
- Research decision-making
- Reproducible methods
- Ethical handling of participant data

## What's Included
- Sample data preparation and scale construction
- Representative quantitative analysis
- Qualitative text analysis pipeline (topic modeling, sentiment)

## What's Not Included
- Raw or cleaned datasets (protected for participant privacy)
- Full analysis outputs

Full materials are available upon request for interview or research review.
